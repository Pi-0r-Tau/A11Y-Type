# A11Y-Type
## Accessible typing assistance for any text field

A11Y-Type is a browser extension that reduces typing effort for users with motor disabilities like arthritis and dexterity impairments by providing real-time word suggestions and keyboard-driven auto-complete. It displays a customizable suggestion overlay in any text field, allowing users to complete words with fewer keystrokes while maintaining full keyboard control and accessibility.

It is privacy focused and is fully offline with no third party dependencies.
